Terraform プライベートレジストリーデモサイト

このサイトは、Terraform のプライベートレジストリーのデモ用です。

以下のような Terraform テンプレートでデモ用のプロバイダーを利用できます:

terraform {
  required_providers {
    hello = {
      source  = "tf-demo.ikedam.jp/example/hello"
      version = "~> 1.0.0"
    }
  }
}

data "hello_world" "message" {
}

output "message" {
  value = data.hello_world.message.message
}
